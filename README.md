# Superstore AI Sales Dashboard

An end-to-end data analytics project combining SQL analysis, Power BI visualization, and a Generative AI chatbot layer.

## What it does
- Analyzes real retail sales data (10,000+ rows) using SQL
- Visualizes key metrics (Region, Category, Top Products) in an interactive Power BI dashboard
- Includes an AI chatbot (powered by Groq LLM API) that answers plain-English questions about the sales data

## Tech Stack
SQL (SQLite), Power BI, Python, Streamlit, Groq API
